# JavaScript - Warm Up

## Description
This project introduces the basics of JavaScript programming using Node.js. It covers variables, constants, data types, operators, loops, functions, objects, and modules.

## Learning Objectives
- Understand why JavaScript is useful.
- Run JavaScript scripts using Node.js.
- Create variables and constants using `var`, `let`, and `const`.
- Understand JavaScript data types.
- Use conditional statements (`if` and `else`).
- Use loops (`while` and `for`).
- Understand functions and variable scope.
- Work with objects and arrays.
- Use arithmetic operators.
- Import files and modules.

## Requirements
- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard 16.x
- All files must start with `#!/usr/bin/node`.
- All files must end with a new line.
