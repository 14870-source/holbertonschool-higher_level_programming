# Python - Serialization

## Description
This project introduces serialization and deserialization in Python using JSON.

## Learning Objectives
- Understand serialization and deserialization.
- Convert Python dictionaries into JSON files.
- Load JSON files back into Python objects.
- Use the built-in `json` module.
- Handle files using the `with` statement.

## Files
- `task_00_basic_serialization.py`: Contains functions to serialize Python dictionaries to JSON files and deserialize JSON files back into Python objects.

## Requirements
- Python 3.8.5
- Pycodestyle 2.7.*
- All Python scripts must start with `#!/usr/bin/env python3`.
